# 정도태권도 2관 영상촬영 앱

이름을 누르면 기본 카메라가 열리고, 촬영본이 원본 화질 그대로
갤러리의 `Movies/정도태권도2관/<이름>/` 폴더(= 이름별 앨범)에 저장됩니다.

## APK 만들기 (GitHub Actions)
1. 이 폴더 전체를 GitHub 저장소(main 브랜치)에 업로드
2. 저장소 → Actions 탭 → "Build APK" 실행 완료까지 대기 (약 3~5분)
3. 완료된 실행 화면 하단 Artifacts에서 `정도영상촬영-apk` 다운로드 → 압축 해제 → app-debug.apk
4. 폰으로 옮겨 설치 ("알 수 없는 앱 설치 허용" 필요)

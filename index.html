📂 영상 분류

가져온 영상마다 얼굴을 찾아 보여줘요. 영상마다 오른쪽에 이름을 입력(또는 추천 이름 누르기)하고 아래 일괄 저장을 누르면 정도태권도2관 › 이름 앨범에 한 번에 저장돼요. 원본은 그대로 두고, 날짜 표시 없이 원본 그대로 복사해서 저장해요.

💬 찍은 영상 카톡 보내기

갤러리 전체 폴더에서 명단 이름이 붙은 폴더(예: 김시우, 3학년/김시우)와 이름_날짜 영상을 자동으로 찾아 아이별로 모아요. 이름을 누르면 오늘 찍은 영상이 골라져 있고, 카톡으로 보내기를 누르면 카카오톡에서 받을 채팅방만 고르면 돼요.
